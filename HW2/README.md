## What I did

I showed the main ggplot2 geoms, grouped by the type of data they are used for,
using R's built-in datasets (`mtcars`, `iris`, `economics`, `diamonds`).
I used `dplyr` to count and average the data before plotting.

- **One number:** histogram, density
- **One category:** bar, col
- **Two numbers:** point, smooth
- **Number by category:** boxplot, violin, errorbar
- **Time:** line, area
- **Two categories:** tile
- **Reference lines:** hline, vline
- **Combined:** facet_wrap with labels
